# Permission-Node Database
## A Catalog of Conditional Legal Nodes in the Quran

**Purpose:** This is a living database of the "permission nodes" — the conditional legal bridges (IF [condition] THEN [state change]) that structure the Islamic juridical order. Each entry records the verse, the permission granted, the condition attached, and the 'illa (ratio) that grounds it. The database is meant to be expanded as the network is explored.

**Format:** Each node is recorded in the table below. Fields:
- **Node** — the permission/condition name
- **Verse** — the Quranic citation
- **Permission** — what is allowed
- **Condition** — the condition that must hold
- **'Illa (ratio)** — the underlying reason
- **Category** — the domain (family, penal, property, worship, etc.)

## The Syllogistic Form

Each node can be reconstructed as an implicit legal syllogism:

```
MAJOR: [the general permission or prohibition]
MINOR: [the specific condition]
CONCLUSION: [the resulting state change]
```

**Example — polygamy:**
```
MAJOR: Marriage is permitted (to women of one's choice)
MINOR: But if justice cannot be maintained between multiple wives
CONCLUSION: Then one (monogamy is the fallback)
```

**Example — taqiyya:**
```
MAJOR: Believers may not take disbelievers as allies
MINOR: Except when fearing for their lives (duress)
CONCLUSION: Then concealment is permitted
```

## The 'Illa (Ratio) Register

The ratios that recur across the network:

| 'Illa | Appears in | Purpose |
|-------|-----------|---------|
| **Justice** (*adl*) | Polygamy, qisas, contracts | Preserve equity |
| **Authority** (*qawwama*) | Marriage asymmetry, *daraja* | Preserve belief's precedence |
| **Submission** (*sughar*) | Jizya, dhimma | Condition protection on submission |
| **Self-preservation** (*ikrah*) | Taqiyya, compulsion | Permit what preserves life under duress |
| **Care for the vulnerable** | Zakat, orphans, divorced women, widows | Protect the weak |
| **Restoration** | Expiation nodes (freeing a slave) | Restore the moral order |
| **Deterrence** | Hudud (penal nodes) | Prevent transgression |
| **Mercy / lifting hardship** (*rahma / raf al-haraj*) | Fasting relief (2:185), fidya (2:184), tayammum (5:6), necessity-dietary (2:173, 5:3, 6:145) | Relax an obligation only under a legitimated trigger; divine mercy | 
| **Protective-quorum** | Four-witness (4:15, 24:4), fixed inheritance shares (4:11-12) | Shield the vulnerable (chaste from slander; widow/sister from forcible disinheritance) |
| **Purity / baseline-good** (*tayyibat*) | Tayammum purification (5:6), dietary catalogue (6:145), POB food (5:5) | What is good is the baseline; what is impure is the narrow exclusion |
| **Harm-guard** | Don't forbid lawful (5:87), never hide testimony (2:283) | Protect claims / avoid excess |
